# Wren Security ESLint Rules

Shared ESLint configuration for Wren Security projects.

Supported ESLint versions are 9 and 10.

## React

React rules are available as `@wrensecurity/eslint-config/react`. They require `eslint-plugin-react`,
which has to be installed by the project itself (it is an optional peer dependency). Note that
`eslint-plugin-react` does not support ESLint 10 yet.
